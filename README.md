## Featured Projects

**[Audiobookshelf for Omarchy](https://github.com/jtcarrasco/omarchy-audiobookshelf)**
An Audiobookshelf client for the Omarchy desktop bar and DankMaterialShell: books and
podcasts with synced progress, chapters and covers, fully keyboard-driven. Built in
QML with a small Python backend, and submitted to the Omarchy plugin marketplace.

**[job-search-agent](https://github.com/jtcarrasco/job-search-agent)**
Autonomous Claude Code agent that searches job boards, deduplicates results, and writes
structured Markdown reports. The entire agent is defined in a single instructions file.
No traditional application code, just an LLM with tool access running on a schedule.
